# **App Name**: Campus Connect

## Core Features:

- Smart Scheduling: Suggests optimal event times considering faculty/student availability and venue constraints, minimizing conflicts.
- Intelligent Venue Allocation: Recommends venues based on expected attendance, equipment needs, and historical data.
- Automated Registration: Generates forms, manages sign-ups, and predicts attendance using machine learning models. The LLM will use historical registration and attendance data to inform its tool that predicts event attendance.
- AI-Powered Reminders: Sends automated reminders via email, SMS, or WhatsApp triggered by user behavior and event schedules.
- Personalized Event Feed: Displays a curated list of recommended events based on the student's interests.
- QR Code Check-In: Facilitates quick and easy entry using QR codes for event participants.
- Admin Dashboard: Offers role-based access for students, volunteers, faculty, and admin with separate dashboards.

## Style Guidelines:

- Primary color: A vibrant blue (#29ABE2) to represent connectivity and innovation.
- Background color: Light grey (#F0F2F5) provides a clean, modern backdrop.
- Accent color: A bright orange (#FF9933) to highlight important actions and notifications.
- Body font: 'Inter', a sans-serif font for clear and readable text.
- Headline font: 'Space Grotesk', a geometric sans-serif font for headings and titles, for a modern and tech-forward feel.
- Use clear and intuitive icons to represent event types and features, ensuring ease of navigation.
- Subtle transitions and loading animations to provide a smooth user experience.
